## About the project

This project aim to detect bridge damage using CNN Architectures along with SSD using Python.

### Tools used

Python - CNN, SSD, Image processing

### Dataset

Data Souce - https://jstagedata.jst.go.jp/articles/dataset/Training_images_for_semantic_segmentation_of_bridge_damage_detection/24750210

The data source consists of 5 types of bridge damage. (spalling, leaking, free_lime, cracks, corrosion)
